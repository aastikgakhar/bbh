The big picture

One loop, running all session

Claude drives the plugin. Every request leaves through a single scoped, rate-limited door. Every response comes straight back into the ledger — the one source of truth. Then it repeats, cell by cell, until the whole map is tested.

The walkthrough

How one test travels

Follow a single finding from a hunch to something you can actually submit. It plays on its own — or tap any step.

Safety

The rails that never come off

These aren’t reminders Claude tries to remember — the code refuses to go around them.

Scope

Every request is checked against the target’s scope. Off-target or a neighbouring domain? Refused, with a reason.

Rule 0

If a response carries data belonging to anyone outside the test accounts, the sender redacts it to a count and stops. A stranger’s data is never collected.

Evidence bar

“Not vulnerable” needs 10 real attempts over 5 techniques plus a passing control. A 200 is never allowed to pose as a finding.

Kill switch .bbh/STOP

One file halts all traffic to the target instantly — while local notes and read-only tools keep working, so you can still wrap up.

Stop gate

The session won’t quietly end while the map still has untested work — and it won’t trap you either.

One rate limiter

Every tester shares one throttle, so more parallel work never means more load on the target.

Why a plugin, not just instructions

Soft advice vs. enforced rules

The method as prose

  • Claude goes deep on one bug class and forgets the other thirty.
  • Calls a 200 OK a finding without reading the body.
  • Closes a bug class after one test, not after proving it.
  • Stops early, long before the attack surface is covered.
  • Writes a report from a hunch, with hedge words.

The method as code

  • The ledger opens a cell for every input × every bug class — none get skipped.
  • A hit is only a candidate until a second, independent agent verifies it.
  • A “no” needs its 10 cases + control on file, or the cell stays open.
  • The stop gate refuses to end while real work is open.
  • The report lint rejects hedge words and bad format before it can be written.

Claude stays the brain. bbh is the discipline it can’t forget.
